개인정보처리방침 (Privacy Policy)

시행일: 2026-11-23

1. 목적

YT Daily Report(이하 "도구")는 운영자 본인이 소유·관리하는 유튜브 채널의 통계를 조회하여 운영자 본인의 이메일로 일일 리포트를 발송하는 개인용 도구입니다.

2. 접근하는 데이터

  • YouTube Data API (youtube.readonly): 채널명, 구독자 수, 영상 목록·제목, 공개 조회수·좋아요·댓글 수
  • YouTube Analytics API (yt-analytics.readonly): 조회수, 시청시간, 평균 시청 지속시간, 구독 증감, 유입경로, 콘텐츠 유형별 통계

모든 접근은 읽기 전용이며, 채널·영상·설정을 변경하지 않습니다.

3. 이용 및 보관

  • 조회한 데이터는 일일 리포트 이메일 작성에만 사용됩니다.
  • OAuth 토큰과 영상별 조회수 스냅샷은 운영자의 Google Apps Script 프로젝트 속성에만 저장됩니다.
  • 데이터를 제3자에게 판매·공유·이전하지 않으며, 광고나 다른 목적에 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

본 도구의 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.

본 도구는 YouTube API Services를 사용하며, 이용 시 YouTube 서비스 약관(https://www.youtube.com/t/terms) 및 Google 개인정보처리방침(https://policies.google.com/privacy)이 적용됩니다.

5. 접근 권한 철회

Google 계정 보안 설정의 "서드파티 앱 및 서비스"(https://myaccount.google.com/connections)에서 언제든 접근 권한을 철회할 수 있으며, 철회 시 저장된 토큰은 더 이상 사용되지 않습니다.
